# 로봇SW개발기사 실기 노트

로봇소프트웨어개발기사 실기 대비 웹페이지입니다.
TXT·CSV 입출력과 인코딩, 기구학 FK·IK·MK, 궤적 계획(등속·CUBIC·LSPB·BBPB·RRT*),
경로 탐색(A*·Dijkstra·Floyd), PID 제어, CAN·TCP 통신, 위치 추정·지도를 다룹니다.

- 게시 주소(claude.ai 아티팩트): https://claude.ai/artifact/CiP69jjki3fhoBSXu2Utsz
- 원자료: `C:\KONG_2027Prg\01.로봇SW개발기사\02.로봇SW개발기사_실습`

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `robot_sw_exam.html` | 완성본. 더블클릭하면 브라우저에서 열림 |
| `src/template.html` | 페이지 원본. 글·표·실습판(JS)을 여기서 고침 |
| `src/snip/*.py` | 페이지에 들어가는 예제 코드. 각각 단독 실행 가능 |
| `src/snip/sol/q*.py` | 실기 예상 문제 모범 답안 32개 (02 기구학부터 항목당 2문제) |
| `src/problems/` | 예상 문제 입력 파일과 출력 결과(`*_expected.txt`) |
| `src/img/` | 페이지에 넣는 그림 (sample_data 차트 캡처) |
| `sample_data/` | 엑셀 차트 샘플과 원본 TXT·CSV (09 단원 자료) |
| `tools/check_solutions.py` | 모범 답안을 모두 실행해 출력 결과 파일을 다시 만듦 |
| `build.py` | 원본 + 예제 코드 → 완성본 생성 |
| `dist/artifact_body.html` | 아티팩트 게시용 본문 (빌드 결과) |

## 수정하는 법

1. 글이나 표는 `src/template.html`, 예제 코드는 `src/snip/`, 예상 문제 답안은 `src/snip/sol/`, 입력 파일은 `src/problems/` 에서 고칩니다.
   예상 문제를 고쳤으면 `python tools/check_solutions.py` 로 출력 결과를 다시 만듭니다.
2. 예제 코드를 고쳤으면 그 파일을 직접 실행해서 주석에 적은 결과가 나오는지 확인합니다.
3. `python build.py` 를 실행합니다.
4. `robot_sw_exam.html` 을 브라우저로 열어 확인합니다.

`src/template.html` 안에서 예제 코드는 `{{파일명.py|설명}}`, 텍스트 파일 내용은 `{{file:problems/파일|설명}}` 형식으로 넣습니다.

## 항목 구성

모든 항목은 1 개념 · 2 주요 내용 요약 · 3 주의해야 될 내용 · 4 상세 내용(실습판) · 5 프로그램 CODE 순서이고, 02 기구학부터는 6 실기 시험 예상 문제 2개(입력 파일, 요구사항, 모범 답안, 출력 결과)가 붙습니다. 01 함수 설명 & 파일 처리에는 예상 문제가 없습니다.

| 단원 | 항목 |
|---|---|
| 01 함수 설명 & 파일 처리 | 1-1 사용 함수, 1-2 TXT, 1-3 CSV, 1-4 인코딩 |
| 02 기구학 | 2-1 FK, 2-2 IK, 2-3 MK |
| 03 궤적 계획 | 3-1 등속·CUBIC, 3-2 LSPB·BBPB, 3-3 RRT* |
| 04 경로 탐색 | 4-1 Dijkstra, 4-2 A*, 4-3 Floyd-Warshall |
| 05 제어 | 5-1 PID |
| 06 동역학 | 6-1 동역학 Computed-Torque |
| 07 통신·모니터링 | 7-1 CAN, 7-2 TCP/IP·SLCAN·SDO, 7-3 상태 모니터링 |
| 08 위치 추정·지도 | 8-1 파티클 필터, 8-2 점유 격자 지도 |
| 09 Mistake Check List | 제출 전 점검 목록 |
| 10 엑셀로 차트 그리기 | 10-1 관절 위치 차트, 10-2 A* 경로 + Block 차트 (sample_data 엑셀 파일 기준) |

예상 문제 파일 이름 `q<단원><항목>_<번호>`는 처음 만들 때의 번호를 그대로 씁니다. 예: `q22_1` = 2-2 IK 예상 문제 1, `q52_1` = 6-1 동역학 예상 문제 1, `q61_1` = 7-1 CAN, `q91_1` = 10-1 관절 위치 차트. 각 문제의 상세 설명은 `src/problems/<문제>_explain.html`.
