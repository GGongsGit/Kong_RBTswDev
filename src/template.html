3주의해야 될 내용
  • np.cos, np.sin, math.cos는 라디안만 받습니다. 도 단위 입력은 np.deg2rad 먼저, 출력이 도면 np.degrees로 되돌립니다.
  • np.arctan2(y, x)는 y가 먼저입니다. 순서를 바꾸면 다른 각도가 나옵니다.
  • int("45.5")는 오류입니다. 소수가 섞일 수 있으면 float()로 읽고 필요할 때 int().
  • round()는 .5에 딱 걸리면 짝수 쪽으로 갑니다(round(0.5) = 0). 출력 자리수는 f"{v:.2f}"로 맞추는 것이 안전합니다.
  • split()(인자 없음)은 여러 칸 공백을 하나로 보지만, split(" ")은 빈 문자열이 생깁니다.
  • range(a, b), np.arange(a, b)는 b를 포함하지 않습니다. 끝점까지 필요하면 np.linspace.
  • np.arccos에 1.0000001처럼 범위를 살짝 넘는 값이 들어가면 nan이 됩니다. np.clip(v, -1, 1)로 감쌉니다.
    • np.clip(v, -1, 1)은 v를 −1과 1 사이로 잘라 내는 함수입니다.
    • 범위 안이면 값이 그대로 나옵니다.
    • −1보다 작으면 −1, 1보다 크면 1로 바꿉니다.
  • heapq는 가장 작은 값이 먼저 나옵니다. 튜플은 첫 값으로 비교하므로 (거리, 노드) 순서로 넣습니다.

TXT 파일 입출력

실기 문제의 입력과 출력은 대부분 공백으로 구분된 TXT 파일입니다.

1개념

파일을 열고(open) 한 줄씩 읽어 문자열을 숫자로 바꾼 뒤 계산하고, 결과를 요구한 형식의 문자열로 만들어 씁니다. with open(...) as f:를 쓰면 블록이 끝날 때 파일이 자동으로 닫힙니다.

2주요 내용 요약
작업코드메모
읽기open(path, "r", encoding="utf-8-sig")for line in f 로 한 줄씩
쓰기open(path, "w", encoding="utf-8")파일이 있으면 덮어씀
이어 쓰기open(path, "a", ...)기존 내용 뒤에 추가
줄 정리line.strip()줄바꿈·앞뒤 공백 제거
나누기line.replace(",", " ").split()쉼표·공백 섞여도 처리
숫자 변환float(v), int(v)split 결과는 문자열
형식 맞추기f"{x:.2f}"소수 자리수 고정
3주의해야 될 내용
  • 경로는 r"C:\..." 원시 문자열로 씁니다. "C:\new"의 \n은 줄바꿈이 됩니다.
  • 빈 줄과 # 주석 줄은 float()에서 오류가 나므로 먼저 걸러냅니다.
  • "w" 모드는 기존 파일을 지웁니다. 여러 번 나눠 쓰려면 처음만 "w", 이후 "a".
  • 중간 계산은 반올림하지 말고 쓸 때만 :.2f로 자릅니다.
  • 문제의 출력 예시와 머리글, 구분자, 소수 자리수, 줄 수가 같은지 마지막에 대조합니다.

IK(Inverse Kinematics, 역기구학/역운동학)

말단 위치 → 관절 각도 · 해석법(코사인 법칙), 수치법(뉴턴-랩슨), 3링크 DH 파라미터

1개념

목표 위치 (x, y)에 닿는 관절 각도를 거꾸로 구합니다. 원점·관절 2·말단이 만드는 삼각형에 코사인 법칙을 쓰면 θ₂가 먼저 나오고, 이어서 θ₁을 구합니다. 해가 없거나 두 개일 수 있습니다.

식으로 풀기 어려운 로봇(3링크 이상, 공간 로봇)은 뉴턴-랩슨(Newton-Raphson) 반복법으로 풉니다. 적당한 초기 각도에서 출발해 「지금 위치와 목표의 차이」를 자코비안으로 나눠 각도를 고치는 일을 오차가 충분히 작아질 때까지 반복합니다.

3링크 이상은 링크마다 DH 파라미터(θ, d, a, α) 네 개로 좌표계를 정의하고, 변환행렬을 차례로 곱해 FK를 만듭니다. 3링크 평면 로봇은 말단 방향 φ까지 주어지면 3번 링크를 빼서 손목점을 구한 뒤 2링크 IK로 풀 수 있습니다.

2주요 내용 요약
cos θ₂ = (x² + y² − L₁² − L₂²) / (2·L₁·L₂) θ₂ = ± arccos(cos θ₂) # 해 2개 (팔꿈치 위/아래) θ₁ = atan2(y, x) − atan2(L₂·sin θ₂, L₁ + L₂·cos θ₂) # 도달 조건: |L₁ − L₂| ≤ √(x²+y²) ≤ L₁ + L₂
# 뉴턴-랩슨 (수치법) f(θ) = FK(θ) − 목표 # 잔차, 0이 되게 만들 것 θ ← θ − J(θ)⁻¹ · f(θ) # J = 2-3 동기구학의 자코비안 ‖f(θ)‖ < tol 이면 종료 # 보통 4~6번이면 수렴
# 3링크 · DH 파라미터 Aᵢ = Rz(θᵢ)·Tz(dᵢ)·Tx(aᵢ)·Rx(αᵢ) T = A₁·A₂·A₃ → 말단 (x, y, φ) # 손목점 방법 (φ가 주어질 때) x_w = x − L₃·cos φ y_w = y − L₃·sin φ → 2링크 IK로 θ₁, θ₂ θ₃ = φ − θ₁ − θ₂
3주의해야 될 내용
  • np.arctan2(y, x) 사용 함 - atan(y/x)는 2·3사분면을 구분하지 못하고 x = 0에서 0으로 나누기가 되므로 사용상의 제약이 많음
  • arccos 인자가 수치 오차로 1을 살짝 넘으면 NaN이 됩니다. np.clip(c2, -1, 1).
  • 도달 불가 위치는 먼저 걸러 냅니다. 문제가 요구하는 표시(예: UNREACHABLE)를 그대로 씁니다.
  • θ₂ 부호와 팔꿈치 위·아래 이름은 교재마다 반대일 수 있습니다. 문제의 정의를 따릅니다.
  • 결과는 FK에 다시 넣어 목표 위치가 나오는지 검산합니다.
  • 뉴턴-랩슨: 어느 해로 수렴할지는 초기값이 정합니다. 원하는 자세(팔꿈치 위/아래)에 가까운 값에서 출발합니다.
  • 뉴턴-랩슨: 반복 중 det J ≈ 0(θ₂ ≈ 0°, 180°)이면 다음 각도가 튀어 발산합니다. 팔을 쭉 편 θ₂ = 0을 초기값으로 쓰지 않습니다.
  • 뉴턴-랩슨: 계산은 rad로 하고, 최대 반복 횟수(예: 50)를 두어 수렴하지 않으면 멈춥니다. 도달 불가 목표에서는 수렴하지 않습니다.
  • DH: 표준 DH(Rz·Tz·Tx·Rx)와 수정 DH(Craig, Rx·Tx·Rz·Tz)는 곱하는 순서와 파라미터 번호가 다릅니다. 문제에서 어느 쪽인지 확인합니다.
  • DH: 행렬은 T = A1 @ A2 @ A3 순서로 곱합니다. 순서를 바꾸면 다른 로봇이 됩니다. 평면 로봇은 d = 0, α = 0, a = 링크 길이.
  • 3링크 평면: 위치 (x, y)만 주면 관절이 하나 남아 해가 무수히 많습니다(여유 자유도). 말단 방향 φ를 함께 주거나 θ₃를 정해야 답이 정해집니다.
  • 3링크 평면: 방향 오차는 (a + π) % 2π − π로 감싸서 비교합니다. 360° 차이를 오차로 보면 수렴하지 않습니다.
  • 뉴턴-랩슨: np.linalg.inv(J) @ f보다 np.linalg.solve(J, f). 시험장 PC에 sympy가 없을 수 있으니 자코비안은 직접 미분한 식으로 씁니다.

뉴턴-랩슨 한 번 반복할 때 하는 일

  1. 지금 각도 θ로 FK를 계산해 잔차 f = FK(θ) − 목표를 구합니다.
  2. ‖f‖가 tol보다 작으면 끝냅니다.
  3. 지금 각도에서 자코비안 J(θ)를 계산합니다.
  4. J·Δθ = f 를 풀어 Δθ를 구합니다 (np.linalg.solve).
  5. θ ← θ − Δθ 로 고치고 1로 돌아갑니다.

DH(Denavit-Hartenberg) 표기법은 관절마다 좌표계를 붙이고, 이웃 좌표계 사이를 네 개의 값으로 나타냅니다. θ는 z축 둘레 회전(회전 관절의 변수), d는 z축 방향 이동, a는 x축 방향 길이(링크 길이), α는 x축 둘레 비틀림입니다.

MK(Motion Kinematics, 동기구학)

관절 속도 → 말단 선속도 v = J(θ)·θ̇

1개념

FK 식을 시간으로 미분하면 말단의 선속도가 나옵니다. 관절 속도 θ̇ 앞에 붙는 계수들을 모은 행렬이 자코비안 J(θ)입니다. J는 자세에 따라 값이 바뀌므로 각도마다 새로 계산합니다.

2주요 내용 요약
  • 순방향: v = J @ dth
  • 역방향: dth = np.linalg.solve(J, v)
  • 가속도: a = J @ ddth + Jdot @ dth
  • 특이점: det J = L₁·L₂·sin θ₂ = 0 → θ₂ = 0°, 180°
[ẋ] [−L₁s₁ − L₂s₁₂ −L₂s₁₂] [θ̇₁] [ẏ] = [ L₁c₁ + L₂c₁₂ L₂c₁₂] [θ̇₂] # s₁ = sin θ₁, c₁₂ = cos(θ₁+θ₂)
3주의해야 될 내용
  • θ는 rad, θ̇는 rad/s여야 v가 m/s로 나옵니다. deg/s를 넣으면 57.3배 커집니다.
  • 역속도 전에 |det J|가 0에 가까운지 확인합니다. 특이점 근처에서는 θ̇가 매우 커집니다.
  • np.linalg.inv(J) @ v보다 np.linalg.solve(J, v)가 정확합니다.
  • 말단 가속도에서 Jdot @ dth를 빠뜨리기 쉽습니다. θ̈ = 0이어도 관절이 돌면 구심 가속도가 있습니다.

가속 → 등속 → 감속 (사다리꼴 / 삼각형 속도)

1개념

LSPB(Linear Segment with Parabolic Blends)는 일정 가속도 a로 t_b초 가속하고, 등속으로 가다가, t_b초 감속합니다. 등속 구간이 0이면 BBPB(Bang-Bang, 삼각형 속도)입니다. 산업용 로봇의 기본 운동 프로파일입니다.

2주요 내용 요약
# 이동량 = 가속 + 등속 + 감속 구간 면적 Δq = a·t_b·(t_f − t_b) t_b² − t_f·t_b + Δq/a = 0 → t_b = (t_f − √(t_f² − 4Δq/a)) / 2 v_max = a·t_b # 가능 조건: a ≥ 4Δq / t_f² (등호 = BBPB, t_b = t_f/2)
3주의해야 될 내용
  • np.roots로 풀 때 계수는 [1, −t_f, Δq/a]. 실습 파일 주석의 [2, …]는 틀렸습니다(주석 수정 완료).
  • 근 두 개 중 작은 근이 t_b입니다. 큰 근은 t_f/2보다 커서 의미가 없습니다.
  • 판별식이 음수면 가속도가 부족해 t_f 안에 도착할 수 없습니다.
  • BBPB는 t_b = t_f/2로 고정되어 a = 4Δq/t_f²로 정해집니다. a_max를 그대로 쓰면 목표를 지나칩니다(★★★ 23 수정 완료).
  • Δq < 0(되돌아가는 운동)이면 가속도·속도 부호를 반대로 둡니다.
4상세 내용

RRT*

장애물을 피하는 경유점을 샘플링으로 찾기

1개념

RRT*(Rapidly-exploring Random Tree Star)는 빈 공간에 점을 무작위로 뿌리며 나무를 키워 경로를 찾습니다. 기본 RRT에 부모 다시 고르기와 재연결(rewire)을 더해 반복할수록 경로가 짧아집니다. 결과는 경유점 목록이라, 3-1·3-2 방식으로 시간 궤적을 붙여야 로봇이 움직일 수 있습니다.

2주요 내용 요약
  • 샘플링 → 최근접 노드 → steer(step만큼 전진) → 충돌 검사
  • 반경 r 안 이웃 중 비용이 가장 싼 부모 선택 (RRT*)
  • 새 노드를 거치면 더 싼 이웃은 부모를 바꿈 (RRT*)
  • 목표 허용거리 안이면 후보 경로 기록, 더 짧으면 교체
  • 반경 r = min(γ·√(ln n / n), r_max)
3주의해야 될 내용
  • 충돌 검사는 끝점만 보면 안 되고 선분 전체를 촘촘히 샘플링합니다.
  • 격자 인덱스는 grid[행][열], 연속 좌표는 round()로 셀을 찾습니다. 범위 밖 검사 먼저.
  • 재연결 후에는 중간 노드 비용이 바뀌므로 경로 길이는 경로 점으로 다시 계산합니다.
  • 난수 결과는 실행마다 다릅니다. 시험 답안을 맞춰야 하면 random.seed()를 고정합니다.
  • goal bias가 너무 크면 장애물 앞에서 막히고, step이 너무 크면 좁은 통로를 놓칩니다.

다익스트라 Dijkstra

한 출발점에서 모든 노드까지 최단 거리

1개념

지금까지 확정된 것 중 가장 가까운 노드부터 꺼내서, 그 노드를 거쳐 가는 길로 이웃 거리를 줄여 나갑니다. 가장 가까운 노드는 우선순위 큐(heapq)로 빠르게 꺼냅니다. 간선 가중치가 음수가 아니어야 합니다.

2주요 내용 요약
  • 거리표 dist를 무한대로, 출발점만 0
  • 큐에 (거리, 노드)를 넣고 작은 것부터 꺼냄
  • 꺼낸 거리가 기록보다 크면 건너뜀(오래된 항목)
  • 이웃 v: d + w < dist[v]면 갱신하고 prev[v] = u
  • 경로는 prev를 목표에서 거꾸로 따라가서 뒤집음
  • 복잡도 O((V + E) log V)
3주의해야 될 내용
  • 무방향 그래프는 간선을 양쪽 방향으로 다 넣습니다.
  • 도착 못 하는 노드는 무한대로 남습니다. NO PATH 처리를 잊지 않습니다.
  • 음수 가중치가 있으면 다익스트라는 틀립니다. 벨만-포드를 씁니다.
  • heapq는 최소 힙이라 튜플 첫 원소(거리)가 작을수록 먼저 나옵니다. 순서를 (노드, 거리)로 바꾸면 안 됩니다.
  • 목표 하나만 필요하면 목표를 꺼내는 순간 멈춰도 됩니다.

6-1

동역학 · Computed-Torque

관절을 원하는 대로 움직이는 데 필요한 토크

1개념

동역학은 힘(토크)과 운동의 관계입니다. 로봇팔은 τ = M(q)·q̈ + C(q, q̇) + G(q)로 표현합니다. 원하는 운동에서 토크를 구하면 역동역학, 토크에서 운동을 구하면 순동역학입니다. Computed-Torque 제어는 역동역학으로 토크를 계산해 궤적을 따라갑니다.

2주요 내용 요약
항의미2링크에서
M(q)관성 행렬 (대칭, 양정치)θ₂에 따라 바뀜
C(q, q̇)코리올리·원심력h = m₂·l₁·l_c2·sin θ₂
G(q)중력 토크cos θ에 비례
τ = M(q)·(q̈_d + Kd·(q̇_d − q̇) + Kp·(q_d − q)) + C + G # Computed-Torque
이 식은 어디서 나왔나 · 피드백 선형화 (feedback linearization)
  • 목표: 비선형 항(M, C, G)을 모델로 상쇄해서 로봇을 q̈ = u인 단순한 시스템으로 만든다.
  • 토크 정하기: 운동 방정식 τ = M·q̈ + C + G의 q̈ 자리에 원하는 가속도 u를 넣으면 τ = M(q)·u + C + G. 임의로 정한 식이 아니라 역동역학을 거꾸로 푼 결과입니다.
  • 확인: 이 토크를 넣으면 M·q̈ + C + G = M·u + C + G → M이 역행렬을 가지므로 q̈ = u.
  • u 정하기: 목표 가속도에 PD 보정을 더해 u = q̈_d + Kd·(q̇_d − q̇) + Kp·(q_d − q).
  • 결과: 오차 e = q_d − q가 ë + Kd·ė + Kp·e = 0을 따르므로 Kp, Kd > 0이면 e → 0. Kd = 2√Kp이면 임계감쇠(진동 없이 가장 빨리 수렴).
제어 방법토크모델 필요특징
단순 PIDτ = Kp·e + Ki·∫e + Kd·ė없음모델 없이 오차만으로 토크 결정. 자세에 따라 성능이 달라짐
PD + 중력 보상τ = Kp·e + Kd·ė + G(q)G만중력만 상쇄해서 정지 위치 오차를 없앰
Computed-Torqueτ = M(q)·u + C + GM, C, G 모두비선형 항을 모두 상쇄해 q̈ = u로 만듦. 모델이 틀리면 오차가 남음

어떤 방법을 쓸지는 설계자의 선택입니다. 하지만 「M, C, G를 상쇄해서 q̈ = u로 만들겠다」는 목표를 정하면 토크 식은 τ = M·u + C + G 하나로 정해집니다.

3주의해야 될 내용

  • M은 행렬, C·G는 벡터입니다. M @ ddq + C + G.
  • 순동역학은 np.linalg.solve(M, tau - C - G)로 q̈를 구합니다.
  • 적분은 오일러보다 RK4가 정확합니다(실습 파일 방식).
4상세 내용
M₁₁ = I₁ + I₂ + m₁l_c1² + m₂(l₁² + l_c2² + 2l₁l_c2 cos θ₂) M₁₂ = M₂₁ = I₂ + m₂(l_c2² + l₁l_c2 cos θ₂) M₂₂ = I₂ + m₂l_c2² C₁ = −2h·θ̇₁θ̇₂ − h·θ̇₂² C₂ = h·θ̇₁² G₁ = (m₁l_c1 + m₂l₁)g cos θ₁ + m₂l_c2 g cos(θ₁+θ₂) G₂ = m₂l_c2 g cos(θ₁+θ₂)

파티클 필터 위치 추정

점 여러 개로 로봇 위치의 확률 분포를 표현

1개념

파티클 하나하나가 「로봇이 여기 있을 수도 있다」는 가설입니다. 이동 명령으로 모두 옮기고(예측), 센서 측정과 잘 맞는 파티클에 큰 가중치를 주고(갱신), 가중치가 큰 파티클을 많이 복제(재샘플링)하면 파티클이 실제 위치로 모입니다.

2주요 내용 요약
  • 예측: 속도 모델 (v, ω)에 잡음을 섞어 이동
  • 갱신: w ∝ exp(−(z − ẑ)² / 2σ²)
  • 정규화: Σw = 1
  • 재샘플링: 저분산(systematic) 방식
  • 추정: 가중 평균, 각도는 atan2(Σw·sin, Σw·cos)
3주의해야 될 내용
  • 가중치는 반드시 정규화합니다. 합이 0에 가까우면(모두 측정과 안 맞음) 균등 분포로 다시 시작합니다.
  • 각도를 그냥 평균하면 179°와 −179°가 0°가 됩니다. sin, cos 평균 후 atan2.
  • 각도는 (a + π) % 2π − π로 [−π, π] 정규화.
  • 저분산 재샘플링은 난수를 한 번만 뽑고 1/M 간격으로 고릅니다. 시험에서는 그 난수를 고정값으로 줄 수 있습니다.
  • 센서 표준편차 σ가 너무 작으면 파티클이 금방 한 점으로 몰려 다양성을 잃습니다.
4상세 내용
# 저분산 재샘플링 (M개) r ~ U(0, 1/M) # 한 번만 for m in 0..M−1: u = r + m/M while u > 누적가중치[i]: i += 1 선택 i

마지막에만

격자
grid[행][열]

궤적
끝 시간 포함

np.arange(0, tf, dt)는 tf가 빠집니다. tf + dt/2 또는 np.linspace.

BBPB
가속도는 계산값

t_b = t_f/2이면 a = 4·Δq/t_f². 마지막 위치가 q_f인지 출력해서 확인합니다.
