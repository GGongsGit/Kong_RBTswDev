문제를 한 줄로

로봇 위치 후보(파티클) 5개 중 센서 측정과 잘 맞는 후보에 높은 점수(가중치)를 주고, 점수로 평균 내어 위치를 추정하는 문제입니다.

풀이 아이디어

로봇은 10.0에 있는 표지판까지 거리를 3.0으로 쟀습니다. 후보가 x에 있다면 예상 거리는 10 − x입니다. 예상 거리가 3.0에 가까울수록 진짜 위치일 가능성이 높습니다.

점수는 종 모양 곡선(가우시안) exp(−(예상 − 측정)² / (2σ²)) 로 줍니다. 차이가 0이면 1, 차이가 클수록 0에 가까워집니다. 점수를 모두 더해 1이 되도록 나누면(정규화) 확률처럼 쓸 수 있고, 위치 추정은 Σ(위치 × 가중치)입니다.

코드 순서
  1. 주석을 빼고 파티클 위치를 읽습니다.
  2. 각 파티클 점수 w = exp(−((10 − x) − 3)² / (2×0.5²))
  3. 합으로 나눠 정규화합니다.
  4. 가중 평균 Σ x·w 를 구합니다.
숫자로 확인
x = 7.0: 예상 3.0, 차이 0   → exp(0)    = 1.000
x = 7.4: 예상 2.6, 차이 −0.4 → exp(−0.32) = 0.726
x = 6.2: 예상 3.8, 차이 0.8  → exp(−1.28) = 0.278
합 ≈ 2.104 → 7.0의 가중치 = 1/2.104 = 0.4752
추정 = 5.5×0.0053 + 6.2×0.1321 + 7.0×0.4752 + 7.4×0.3451 + 8.1×0.0423 = 7.071

진짜 위치는 7.0일 가능성이 가장 높고, 7.4 쪽도 꽤 맞아서 추정값이 7.0보다 약간 큰 7.071이 되었습니다.

자주 하는 실수
  • 정규화를 하지 않으면 가중 평균이 위치 단위가 아니게 됩니다.
  • σ를 너무 작게 하면 7.0 하나에만 점수가 몰려 다른 후보가 모두 사라집니다.
