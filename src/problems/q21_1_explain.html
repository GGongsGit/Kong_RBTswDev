문제를 한 줄로

세 관절 각도를 받아서, 팔 끝(말단)이 어디에 있는지 x, y 좌표를 구하는 문제입니다.

풀이 아이디어

팔 하나하나를 「길이와 방향이 있는 화살표」로 생각합니다. 화살표 세 개를 꼬리에 머리를 붙여 이으면 끝점이 말단입니다. 화살표의 x 성분은 길이 × cos(방향), y 성분은 길이 × sin(방향)입니다.

주의할 점은 방향입니다. 두 번째 관절 각도 θ₂는 첫 번째 팔에서 얼마나 더 꺾었는지(상대 각도)라서, 두 번째 팔의 실제 방향은 θ₁ + θ₂, 세 번째 팔은 θ₁ + θ₂ + θ₃입니다. 이렇게 앞에서부터 차례로 더한 값을 누적 각이라 하고, np.cumsum이 이 계산을 한 번에 해 줍니다.

코드 순서
  1. 파일을 한 줄씩 읽고, 빈 줄은 건너뜁니다.
  2. 세 각도를 np.deg2rad로 라디안으로 바꿉니다 (cos, sin은 라디안만 받습니다).
  3. np.cumsum으로 누적 각 [θ₁, θ₁+θ₂, θ₁+θ₂+θ₃]를 만듭니다.
  4. 길이 배열 L과 cos(누적 각)을 곱해 모두 더하면 x, sin을 쓰면 y입니다.
  5. f"{x:.2f} {y:.2f}"로 소수 둘째 자리까지 씁니다.
숫자로 확인

두 번째 줄 30 30 30을 손으로 풀어 봅니다. 누적 각은 30°, 60°, 90°입니다.

x = 0.5·cos30° + 0.4·cos60° + 0.3·cos90°
  = 0.5×0.866 + 0.4×0.5 + 0.3×0 = 0.433 + 0.2 + 0 = 0.633 → 0.63
y = 0.5·sin30° + 0.4·sin60° + 0.3·sin90°
  = 0.25 + 0.346 + 0.3 = 0.896 → 0.90

출력 결과의 둘째 줄 0.63 0.90과 같습니다. 첫 줄 0 0 0은 팔이 x축으로 쭉 펴진 상태라 x = 0.5+0.4+0.3 = 1.20, y = 0입니다.

자주 하는 실수
  • 각도를 라디안으로 바꾸지 않고 np.cos(30)을 계산하면 30 라디안(약 1719°)의 cos가 나와 전혀 다른 값이 됩니다.
  • 두 번째 팔에 θ₂만 넣으면 안 됩니다. 반드시 누적 각을 씁니다.
  • round()로 중간 값을 자르지 말고, 마지막에 쓸 때만 :.2f로 자릅니다.
