문제를 한 줄로

10°에서 70°까지 3초 동안, 출발과 도착 때 멈춰 있도록 부드럽게 움직이는 위치·속도·가속도 표를 만드는 문제입니다.

풀이 아이디어

CUBIC은 위치를 3차식 q(t) = a₀ + a₁t + a₂t² + a₃t³ 으로 둡니다. 모르는 계수가 4개이니 조건 4개가 필요합니다: 시작 위치, 시작 속도(0), 끝 위치, 끝 속도(0). 이 4개 조건으로 연립방정식 AX = B 를 세워 np.linalg.solve로 풉니다.

속도는 위치를 한 번 미분한 q'(t) = a₁ + 2a₂t + 3a₃t², 가속도는 두 번 미분한 q''(t) = 2a₂ + 6a₃t 입니다.

코드 순서
  1. 입력 파일에서 이름 값 형식을 딕셔너리로 읽습니다.
  2. 각도는 라디안으로 바꿔 계수를 구합니다.
  3. 4×4 행렬 A와 B = [q₀, 0, q_f, 0]으로 계수를 풉니다.
  4. np.arange(0, tf + dt/2, dt)로 0, 0.5, …, 3.0 시간을 만듭니다.
  5. 위치·속도·가속도를 계산해 도 단위로 바꿔 CSV에 씁니다.
숫자로 확인

v₀ = v_f = 0이면 공식이 간단해집니다 (Δq = 60°, t_f = 3 s).

a₂ = 3Δq / t_f² = 3×60 / 9 = 20 °/s²       (rad로 0.34907)
a₃ = −2Δq / t_f³ = −120 / 27 = −4.444 °/s³  (rad로 −0.07757)
t = 1.5 s (가운데): q = 10 + 20×2.25 − 4.444×3.375 = 10 + 45 − 15 = 40°
                   v = 2×20×1.5 − 3×4.444×2.25 = 60 − 30 = 30 °/s  ← 최대 속도
                   a = 40 − 6×4.444×1.5 = 0

가운데에서 속도가 가장 빠르고 가속도가 0, 처음 가속도 40 °/s²에서 끝 −40 °/s²까지 직선으로 바뀝니다. 출력 표와 같습니다.

자주 하는 실수
  • np.arange(0, tf, dt)는 끝값 3.0이 빠집니다. tf + dt/2까지로 해야 3.0이 들어갑니다.
  • 계수를 도 단위로 구하고 출력도 도로 하면 결과는 같지만, 섞어 쓰면 틀립니다. 한 단위로 통일합니다.
