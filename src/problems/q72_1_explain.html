문제를 한 줄로

ROS가 만든 지도 숫자(−1, 0~100)를 그림 파일(PGM)의 밝기 값으로 바꾸고, 위아래를 뒤집어 저장하는 문제입니다.

풀이 아이디어

지도의 각 칸 값은 −1(모름), 0~100(막혀 있을 확률 %)입니다. 그림으로 저장할 때 map_saver 규칙은: 모름 → 205(회색), 65 이상 → 0(검정, 막힘), 나머지 → 254(흰색, 비어 있음).

ROS 지도는 0번째 줄이 아래쪽이지만, 그림 파일은 0번째 줄이 위쪽입니다. 그래서 줄 순서를 뒤집어서([::-1]) 저장해야 그림이 거꾸로 보이지 않습니다.

코드 순서
  1. 격자 숫자를 읽습니다.
  2. 칸마다 규칙으로 픽셀 값을 정합니다.
  3. 줄 순서를 뒤집습니다.
  4. P2(텍스트 PGM) 머리글: P2, 폭 높이, 최대값 255를 쓰고 픽셀을 씁니다.
숫자로 확인
입력 (첫 줄이 아래)          변환               뒤집어서 저장 (첫 줄이 위)
−1 −1  0   0          205 205 254 254        254   0 254   0
 0  0  0 100    →     254 254 254   0   →    254 254 254   0
 0 80 50 100          254   0 254   0        205 205 254 254

80은 65 이상이라 검정, 50은 65 미만이라 흰색입니다.

자주 하는 실수
  • 경계값 65를 「초과」로 처리하면 65인 칸이 흰색이 됩니다. 「이상」입니다.
  • 뒤집지 않으면 지도가 위아래 반대로 보입니다.
