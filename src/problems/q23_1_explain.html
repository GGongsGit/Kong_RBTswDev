문제를 한 줄로

관절이 돌아가는 속도(θ̇)가 주어질 때, 팔 끝이 움직이는 속도(선속도 vx, vy)를 구하는 문제입니다.

풀이 아이디어

팔 끝 위치 x, y는 각도의 함수입니다. 각도가 시간에 따라 변하면 위치도 변하고, 그 변화율이 속도입니다. 미분하면 v = J(θ)·θ̇ 꼴이 되는데, 자코비안 J는 「관절이 조금 돌 때 끝이 얼마나 움직이는지」를 모아 놓은 2×2 표(행렬)입니다.

J = [ −L₁sinθ₁ − L₂sin(θ₁+θ₂)   −L₂sin(θ₁+θ₂) ]
    [  L₁cosθ₁ + L₂cos(θ₁+θ₂)    L₂cos(θ₁+θ₂) ]
v = J @ [θ̇₁, θ̇₂]

속도의 크기는 |v| = √(vx² + vy²)입니다.

코드 순서
  1. 각 줄에서 θ₁, θ₂(도), θ̇₁, θ̇₂(rad/s) 네 값을 읽습니다.
  2. 각도만 라디안으로 바꿉니다. θ̇는 이미 rad/s라 그대로 씁니다.
  3. J를 만들고 J @ [w1, w2]로 v를 구합니다 (@는 행렬 곱).
  4. np.linalg.norm(v)로 크기를 구합니다.
숫자로 확인

둘째 줄 0 90 1.0 0.0: 첫 팔은 오른쪽, 두 번째 팔은 위를 향하고, 관절 1만 1 rad/s로 돕니다.

θ₁ = 0°, θ₁+θ₂ = 90°
J = [ −sin0 − sin90   −sin90 ] = [ −1  −1 ]
    [  cos0 + cos90    cos90 ]   [  1   0 ]
v = J @ [1, 0] = (−1, 1)    |v| = √2 = 1.4142

팔 전체가 원점을 중심으로 돌기 때문에 끝(1, 1)은 원을 따라 왼쪽 위로 움직입니다. 출력 -1.0000 1.0000 1.4142와 같습니다.

자주 하는 실수
  • θ̇에 deg2rad를 또 하면 안 됩니다. 이미 rad/s입니다. 반대로 θ에는 꼭 해야 합니다.
  • J * w(원소별 곱)와 J @ w(행렬 곱)는 다릅니다. 행렬 곱은 @입니다.
