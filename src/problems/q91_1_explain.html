문제를 한 줄로

관절 각도 파일을 엑셀에 넣고, 엑셀 수식으로 팔의 관절·말단 좌표를 계산한 뒤, 자세마다 원점–관절–말단을 잇는 차트를 그리는 문제입니다.

풀이 아이디어

Python에서 값을 계산해 넣지 않고 엑셀 수식을 넣는 이유는, 나중에 엑셀에서 각도만 바꿔도 좌표와 차트가 자동으로 바뀌게 하기 위해서입니다. openpyxl에서 셀에 "=$B$1*COS(RADIANS(B5))"처럼 = 로 시작하는 문자열을 넣으면 수식이 됩니다.

$B$1의 $는 「이 칸에 고정」이라는 뜻입니다. 아래 줄로 수식을 복사해도 링크 길이 칸은 바뀌지 않습니다.

코드 순서
  1. B1, B2에 L1, L2를 넣습니다.
  2. 5행부터 자세마다 θ1, θ2와 FK 수식(x1, y1, x2, y2)을 넣습니다.
  3. 차트용으로 자세마다 3점(원점, 관절, 말단)을 세로로 늘어놓은 K, L열을 만듭니다(=D5 같은 참조).
  4. ScatterChart에 자세마다 계열 하나(X = K열 3칸, Y = L열 3칸)를 추가합니다.
  5. 축 범위를 맞추고 저장한 뒤, 같은 계산을 Python으로 해서 검산 값을 출력합니다.
숫자로 확인
자세 1 (30°, 45°), L1 0.85, L2 0.65
x1 = 0.85·cos30° = 0.7361,  y1 = 0.4250
x2 = 0.7361 + 0.65·cos75° = 0.9044,  y2 = 1.0529

검산 값이 sample_data의 PxPy_data.txt와 똑같습니다. 즉 그 파일도 같은 FK로 만든 것입니다. 엑셀에서 열면 수식이 계산되어 차트가 그려집니다.

자주 하는 실수
  • 엑셀 COS는 라디안을 받습니다. RADIANS()로 바꾸지 않으면 30을 30 라디안으로 계산합니다.
  • openpyxl은 수식의 결과를 계산하지 않습니다. Python으로 다시 읽으면 값이 비어 있으니 검산은 Python으로 따로 합니다.
