문제를 한 줄로

주어진 거리·시간·최대 가속도로 사다리꼴(LSPB) 운동이 가능한지, 딱 삼각형(BBPB)인지, 불가능한지 판정하는 문제입니다.

풀이 아이디어

앞 문제의 이차방정식 t_b² − t_f·t_b + Δq/a = 0 에서 판별식 t_f² − 4Δq/a 가 0 이상이어야 실수 해가 있습니다. 정리하면 a ≥ 4Δq / t_f² 입니다. 이 값을 a_min(필요한 최소 가속도)이라 하면:

a > a_min  → 사다리꼴(등속 구간 있음)  LSPB
a = a_min  → 삼각형(가속 끝나자마자 감속) BBPB
a < a_min  → 시간 안에 못 감             IMPOSSIBLE
코드 순서
  1. 줄마다 Δq, t_f, a_max를 읽습니다.
  2. a_min = 4|Δq| / t_f²
  3. 부동소수 비교라 같음은 abs(a − a_min) < 1e-9로 판단합니다.
숫자로 확인
1.0 2.0 2.0 : a_min = 4×1/4 = 1.0  → 2.0 > 1.0  LSPB
1.0 2.0 1.0 : a_min = 1.0         → 같음      BBPB
1.0 2.0 0.8 : a_min = 1.0         → 0.8 < 1.0 IMPOSSIBLE
0.5 1.0 3.0 : a_min = 4×0.5/1 = 2.0 → 3.0 > 2.0 LSPB
자주 하는 실수
  • a == a_min처럼 실수를 ==로 비교하면 0.30000000000000004 같은 오차 때문에 틀릴 수 있습니다.
  • Δq가 음수(되돌아가기)일 때도 판정은 거리이므로 절댓값을 씁니다.
