문제를 한 줄로

앞 문제와 반대로, 회전수·전류·온도·고장 값을 CAN 메시지의 8바이트로 만드는 문제입니다.

풀이 아이디어

디코딩의 반대 순서입니다. 물리값을 factor로 나눠 정수(raw)로 만들고, 정해진 바이트 수만큼 리틀 엔디언으로 쪼갭니다. 전류는 음수가 될 수 있어 signed로 바꿉니다.

(3000).to_bytes(2, "little")는 3000 = 0x0BB8을 [B8, 0B] 두 바이트로 만듭니다.

코드 순서
  1. 줄마다 rpm, 전류, 온도, 고장을 읽습니다.
  2. raw 전류 = round(전류 / 0.01)
  3. rpm(2바이트) + 전류(2바이트, signed) + 온도 + 고장 + 0 + 0 을 이어 붙입니다.
  4. 각 바이트를 두 자리 16진수 대문자로 씁니다.
숫자로 확인
3000 −1.00 75 0
  3000 = 0x0BB8 → B8 0B
  −1.00 / 0.01 = −100 → 16비트 2의 보수 0xFF9C → 9C FF
  75 = 0x4B,  0 = 00
  → B8 0B 9C FF 4B 00 00 00

첫 줄 결과 10 27 05 00 32 01 00 00은 앞 문제 로그의 첫 메시지와 같아서, 인코딩·디코딩이 서로 맞는 것을 확인할 수 있습니다.

자주 하는 실수
  • 0.05 / 0.01 같은 계산은 4.999999…가 될 수 있어 int()로 자르면 4가 됩니다. 반드시 round().
  • f"{x:02X}"에서 02를 빼면 5가 05가 아니라 5로 나와 자리가 어긋납니다.
