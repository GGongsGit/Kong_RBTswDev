문제를 한 줄로

팔 끝이 가야 할 목표 위치 (x, y)가 주어질 때, 그 위치에 닿는 관절 각도 두 쌍을 구하는 문제입니다. 닿을 수 없으면 UNREACHABLE을 씁니다.

풀이 아이디어

원점, 관절 2, 말단은 세 변의 길이가 L₁, L₂, r(원점–목표 거리)인 삼각형을 이룹니다. 세 변을 알면 코사인 법칙으로 각을 구할 수 있습니다: r² = L₁² + L₂² + 2L₁L₂cos θ₂ 이므로 cos θ₂ = (r² − L₁² − L₂²) / (2L₁L₂).

cos 값이 같은 각은 +θ와 −θ 두 개라서 해가 두 개(팔꿈치를 위로 꺾기 / 아래로 꺾기)입니다. θ₁은 「목표 방향 각 − 팔이 안쪽으로 꺾인 만큼」으로 구합니다.

삼각형이 만들어지려면 r이 L₁ + L₂보다 크면 안 되고(팔이 다 펴도 안 닿음), |L₁ − L₂|보다 작아도 안 됩니다(너무 가까워서 접어도 안 됨).

코드 순서
  1. r = np.hypot(x, y)로 거리를 구하고, 범위 밖이면 UNREACHABLE을 씁니다.
  2. cos θ₂ 값을 계산하고 np.clip으로 −1~1 사이로 묶습니다.
  3. θ₂ = ±arccos(cos θ₂) 두 경우를 반복문으로 돌립니다.
  4. θ₁ = atan2(y, x) − atan2(L₂ sin θ₂, L₁ + L₂ cos θ₂)
  5. 도로 바꿔 소수 둘째 자리로 씁니다.
숫자로 확인

첫 줄 (1.2, 0.7), L₁ = 1.0, L₂ = 0.8

r² = 1.2² + 0.7² = 1.44 + 0.49 = 1.93
cos θ₂ = (1.93 − 1 − 0.64) / (2×1×0.8) = 0.29 / 1.6 = 0.18125
θ₂ = ±arccos(0.18125) = ±79.56°
해 a (θ₂ = +79.56°):
  atan2(0.7, 1.2) = 30.26°
  atan2(0.8·sin79.56°, 1 + 0.8·cos79.56°) = atan2(0.787, 1.145) = 34.50°
  θ₁ = 30.26° − 34.50° = −4.24°

(2.0, 0.5)는 r = 2.06 > 1.8이라 너무 멀고, (0.1, 0.1)은 r = 0.14 < 0.2라 너무 가까워서 둘 다 UNREACHABLE입니다. (0, 1.8)은 r = 1.8로 팔을 다 편 경계라서 θ₂ = 0이 되어 두 해가 같습니다.

자주 하는 실수
  • atan(y/x)를 쓰면 x가 음수인 (−1.0, 1.0)에서 180° 틀린 답이 나옵니다. 반드시 atan2.
  • 경계값(r = L₁ + L₂)에서 계산 오차로 cos θ₂가 1.0000000002가 되면 arccos가 NaN이 됩니다. clip이 이것을 막습니다.
  • -0.00이 출력되지 않도록 반올림 후 + 0.0을 해 줍니다.
