문제를 한 줄로

미터 단위 실제 좌표가 지도의 몇 번째 칸(열, 행)에 해당하는지 계산하고, 지도 안에 있는지 확인하는 문제입니다.

풀이 아이디어

지도 한 칸이 0.05 m(5 cm)이고, 지도의 왼쪽 아래 모서리가 실제 좌표 (−1.00, −2.00)입니다. 그러니 「원점에서 몇 m 떨어졌는지 ÷ 칸 크기」가 칸 번호이고, 소수점은 버립니다(내림).

열 = floor((x − origin_x) / 0.05)
행 = floor((y − origin_y) / 0.05)
0 ≤ 열 < 100, 0 ≤ 행 < 80 이면 지도 안
코드 순서
  1. 주석을 빼고 x, y를 읽습니다.
  2. math.floor로 열, 행을 구합니다.
  3. 범위 안이면 YES, 아니면 NO.
숫자로 확인
(0, 0)       : (0 − (−1))/0.05 = 20,   (0 − (−2))/0.05 = 40  → (20, 40)
(1.234, 0.987): 2.234/0.05 = 44.68 → 44,   2.987/0.05 = 59.74 → 59
(4.20, 0)    : 5.2/0.05 = 104 → 100 이상이라 지도 밖 → NO

(−1.00, −2.00)은 지도 왼쪽 아래 모서리 칸 (0, 0)입니다.

자주 하는 실수
  • int()는 음수에서 0 쪽으로 자릅니다(int(−0.5) = 0). 지도 밖 음수 좌표가 0번 칸으로 잘못 들어가니 floor를 씁니다.
  • 3.97 → 99.4처럼 경계 근처는 계산 오차가 있을 수 있어 아주 작은 값(1e−9)을 더해 내림합니다.
