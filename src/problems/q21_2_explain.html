문제를 한 줄로

2링크 팔의 관절 2 위치와 말단 위치를 구하고, 원점에서 말단까지 거리도 구하는 문제입니다.

풀이 아이디어

관절 2는 첫 번째 팔의 끝이라 (L₁cos θ₁, L₁sin θ₁)입니다. 말단은 그 점에서 두 번째 팔(방향 θ₁+θ₂)만큼 더 간 점입니다. 원점에서 말단까지 거리는 피타고라스 정리 √(x² + y²)이고, numpy에서는 np.hypot(x, y)가 이 계산을 합니다.

코드 순서
  1. 머리글 x1 y1 x2 y2 r을 먼저 씁니다.
  2. 한 줄의 θ₁, θ₂를 라디안으로 바꿉니다.
  3. x1, y1 = L₁cos θ₁, L₁sin θ₁
  4. x2 = x1 + L₂cos(θ₁+θ₂), y2 = y1 + L₂sin(θ₁+θ₂)
  5. r = np.hypot(x2, y2), 모두 소수 넷째 자리로 씁니다.
숫자로 확인

첫 줄 30 45 (L₁ = 0.85, L₂ = 0.65)

x1 = 0.85·cos30° = 0.85×0.8660 = 0.7361    y1 = 0.85·sin30° = 0.4250
방향 = 30°+45° = 75°
x2 = 0.7361 + 0.65·cos75° = 0.7361 + 0.1682 = 0.9044 (반올림)
y2 = 0.4250 + 0.65·sin75° = 0.4250 + 0.6279 = 1.0529
r  = √(0.9044² + 1.0529²) = √(0.8180 + 1.1086) = √1.9266 = 1.3879

둘째 줄 90 90은 첫 팔이 위(+y), 두 번째 팔이 180°(왼쪽)를 향해 말단이 (−0.65, 0.85)가 됩니다. 그림을 그려 보면 바로 확인됩니다.

자주 하는 실수
  • r을 구할 때 관절 2 좌표(x1, y1)를 쓰면 안 됩니다. 말단(x2, y2)입니다.
  • -0.0000처럼 음수 0이 나오면 보기 싫으니 필요하면 round(v, 4) + 0.0으로 정리합니다.
