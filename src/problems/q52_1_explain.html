문제를 한 줄로

2링크 로봇 팔이 주어진 자세·속도·가속도로 움직이려면 각 관절 모터가 얼마의 힘(토크)을 내야 하는지 계산하는 문제입니다.

풀이 아이디어

뉴턴의 법칙 F = m·a를 회전에 쓰면 「토크 = 관성 × 각가속도」입니다. 로봇 팔은 여기에 두 가지가 더해집니다.

M(q)·q̈: 팔을 가속하는 데 필요한 토크 (M은 자세에 따라 바뀌는 관성 표).
C: 팔이 돌 때 생기는 원심력·코리올리 효과.
G: 팔 무게를 버티는 데 필요한 토크 (팔이 수평일 때 가장 큼).

τ = M(q)·q̈ + C(q, q̇) + G(q)
코드 순서
  1. 각 줄에서 q(도), q̇, q̈를 읽고 q만 라디안으로 바꿉니다.
  2. M(2×2), C(2개), G(2개)를 식대로 계산합니다.
  3. τ = M @ q̈ + C + G 를 소수 셋째 자리로 씁니다.
숫자로 확인

첫 줄은 모두 0 → 팔이 수평으로 가만히 있음. 움직임이 없으니 M·q̈ = 0, C = 0이고 무게만 버티면 됩니다.

G₁ = (m₁·l_c1 + m₂·l₁)·g·cos0 + m₂·l_c2·g·cos0
   = (2×0.5 + 1.5×1.0)×9.81 + 1.5×0.4×9.81 = 24.525 + 5.886 = 30.411 N·m
G₂ = m₂·l_c2·g·cos0 = 1.5×0.4×9.81 = 5.886 N·m

셋째 줄 q₁ = 90°는 팔이 똑바로 위를 향해 cos 90° = 0이라 무게를 버틸 토크가 0입니다(물건을 머리 위로 똑바로 들면 팔이 덜 힘든 것과 같음).

자주 하는 실수
  • 각도 기준을 확인합니다. 이 문제는 θ = 0이 수평이라 cos를 씁니다. 수직 기준이면 sin입니다.
  • M은 행렬이라 M @ ddq로 곱합니다.
