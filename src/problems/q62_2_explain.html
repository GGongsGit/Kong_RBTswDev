문제를 한 줄로

CANopen 모터의 값을 읽어 달라고 요청하는 메시지(SDO 업로드 요청)를 SLCAN 문자열로 만드는 문제입니다.

풀이 아이디어

CANopen 장치 안의 값들은 「주소(index:subindex)」로 정리되어 있습니다(예: 0x6064 = 현재 위치). 값을 읽으려면 ID 0x600 + 노드 번호로 다음 8바이트를 보내고, 장치는 ID 0x580 + 노드 번호로 답합니다.

[0x40, index 아래 바이트, index 위 바이트, subindex, 0, 0, 0, 0]
  0x40 = 「읽기(업로드) 요청」 명령
코드 순서
  1. 줄마다 노드, index(16진수), subindex를 읽습니다.
  2. cob_id = 0x600 + 노드
  3. index를 리틀 엔디언 두 바이트로 나눠 데이터 8바이트를 만듭니다.
  4. f"t{cob_id:03X}8{data.hex().upper()}"로 문자열을 만듭니다.
숫자로 확인
노드 1, index 0x6041, sub 0
  ID = 0x601,  데이터 = 40 41 60 00 00 00 00 00
  → t601 8 4041600000000000  (붙여 쓰면 t60184041600000000000)
  응답 ID = 0x581

index 0x6041을 쓸 때 41이 먼저, 60이 나중입니다(리틀 엔디언).

자주 하는 실수
  • index를 60 41 순서로 쓰면 0x4160이라는 다른 주소를 읽게 됩니다.
  • 실제로 보낼 때는 끝에 \r(줄 끝 문자)를 붙여야 게이트웨이가 한 줄로 인식합니다.
