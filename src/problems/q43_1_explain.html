문제를 한 줄로

네 도시 사이 직접 거리표(INF는 직접 길 없음)가 있을 때, 모든 도시 쌍 사이의 가장 짧은 거리표를 만드는 문제입니다.

풀이 아이디어

플로이드-워셜은 「i에서 j로 갈 때, k를 거쳐 가면 더 짧은가?」를 k = 0, 1, 2, 3 각각에 대해 모든 i, j에 검사합니다. 더 짧으면 표를 고칩니다. 반복문 세 개로 끝나는 짧은 알고리즘입니다.

가장 바깥 반복문이 k(거쳐 가는 도시)여야 합니다. k = 0을 다 끝내야 「0을 거치는 길」이 반영되고, 그다음 k = 1 단계에서 「0이나 1을 거치는 길」이 반영되는 식으로 차곡차곡 쌓이기 때문입니다.

코드 순서
  1. INF 글자는 float("inf")로 바꿔 읽습니다.
  2. for k → for i → for j 순서로 d[i][k] + d[k][j] < d[i][j] 이면 고칩니다.
  3. INF는 INF로, 나머지는 :g(필요 없는 .0 생략)로 씁니다.
숫자로 확인
예: 0 → 2 는 직접 길이 없음(INF)
  k=1: 0→1(3) + 1→2(2) = 5   → d[0][2] = 5
예: 1 → 0 은 직접 8
  k=3: 1→3(… 처음엔 INF) …  k=2 이후 1→2→3→0 = 2+1+2 = 5 < 8  → 5

결과 첫 줄 0 3 5 6: 0→3은 직접 7보다 0→1→2→3 = 3+2+1 = 6이 짧습니다.

자주 하는 실수
  • k를 가장 안쪽 반복문에 두면 일부 경로가 반영되지 않아 틀립니다.
  • 원본 표를 다른 곳에서도 쓴다면 복사본에서 계산합니다.
