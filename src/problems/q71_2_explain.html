문제를 한 줄로

가중치가 큰 파티클은 여러 번, 작은 파티클은 적게(또는 0번) 뽑아 새 파티클 집합을 만드는 재샘플링 문제입니다.

풀이 아이디어

저분산 재샘플링은 0~1 길이의 줄 위에 가중치만큼 칸을 나눠 놓고, 같은 간격(1/M)으로 화살 M개를 쏴서 어느 칸에 맞는지 보는 방법입니다. 시작 위치 r 하나만 정하면 나머지 화살은 1/M씩 떨어져 있습니다. 칸이 넓은(가중치가 큰) 파티클은 화살을 여러 개 맞습니다.

코드 순서
  1. 가중치 목록을 읽습니다. 누적합 c는 첫 가중치부터 시작합니다.
  2. m = 0 ~ M−1에 대해 u = (r + m)/M
  3. u가 누적합보다 크면 다음 파티클로 넘어가며 누적합을 늘립니다.
  4. 멈춘 파티클 번호를 선택합니다.
숫자로 확인
가중치 0.10 0.40 0.05 0.30 0.15  → 누적 0.10 0.50 0.55 0.85 1.00
u = 0.05/5 + m/5 = 0.01, 0.21, 0.41, 0.61, 0.81
0.01 ≤ 0.10 → 0번
0.21, 0.41 ≤ 0.50 → 1번, 1번
0.61, 0.81 ≤ 0.85 → 3번, 3번
선택: 0 1 1 3 3   개수: 1 2 0 2 0

가중치 0.40, 0.30인 1번, 3번이 두 번씩 뽑히고, 가중치가 작은 2번(0.05), 4번(0.15)은 사라졌습니다.

자주 하는 실수
  • 화살마다 난수를 새로 뽑으면 운에 따라 결과가 크게 달라집니다. 저분산 방식은 난수를 한 번만 씁니다.
  • u = r + m/M 인지 (r + m)/M 인지 문제 정의를 확인합니다. 여기서는 (r + m)/M입니다.
