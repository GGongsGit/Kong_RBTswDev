문제를 한 줄로

온도나 속도처럼 천천히 따라오는 시스템(1차계)을 PI 제어기로 목표값 1에 맞출 때, 시간에 따른 출력과 오버슈트를 구하는 문제입니다.

풀이 아이디어

1차계 τ·ẏ = −y + K·u 는 「입력 u를 주면 출력 y가 시간 상수 τ 동안 천천히 따라온다」는 뜻입니다. PI 제어기는 오차 e = 1 − y 에 비례하는 힘(Kp·e)과, 지금까지 쌓인 오차의 합(I)을 더해 u를 만듭니다. 적분이 있어서 결국 오차가 0이 됩니다.

컴퓨터에서는 Ts = 0.01초마다 한 걸음씩 계산합니다(오일러 방법): y_새 = y + Ts × (−y + K·u) / τ.

코드 순서
  1. 입력 파일에서 K, τ, Kp, Ki, Ts, 끝 시간을 읽습니다.
  2. N = T_end / Ts 번 반복하며 매번 y를 기록합니다.
  3. e = 1 − y, u = Kp·e + I, I += Ki·Ts·e
  4. y += Ts·(−y + K·u)/τ
  5. 1, 2, 5, 10초의 y와 최댓값으로 오버슈트 (최댓값 − 1)×100 %를 씁니다.
숫자로 확인

출력 y(1 s) = 0.48, y(2 s) = 0.76으로 점점 올라가 y(5 s) = 1.0101로 목표를 살짝 넘었다가 y(10 s) = 1.0040으로 1에 다가갑니다. 가장 높을 때 1.017 정도라 오버슈트 1.70 %입니다.

Ki를 0으로 하면(P 제어만) 1에 도달하지 못하고 Kp·K/(1 + Kp·K) = 1.2/2.2 ≈ 0.545에 머뭅니다. 적분항이 오차를 없애 준다는 것을 확인할 수 있습니다.

자주 하는 실수
  • 적분할 때 Ts를 곱하지 않으면 적분이 100배 빨리 쌓여 크게 출렁입니다.
  • y를 갱신하기 전에 기록해야 t = 0의 값이 0으로 들어갑니다. 순서를 바꾸면 한 칸씩 밀립니다.
