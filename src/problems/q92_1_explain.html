문제를 한 줄로

격자 지도와 경로를 엑셀에 넣고, 벽 칸의 좌표를 엑셀 수식으로 자동으로 뽑아 경로와 벽을 함께 그리는 문제입니다.

풀이 아이디어

엑셀 차트는 0/1 표를 그림으로 그리지 못하고, 점의 (X, Y) 좌표만 그릴 수 있습니다. 그래서 49칸을 한 줄에 한 칸씩 검사해서 벽이면 (열, 행), 길이면 #N/A를 내는 수식을 J, K열에 넣습니다. 차트는 #N/A를 「값 없음」으로 보고 점을 찍지 않습니다.

칸 번호 k = ROW() − 2   (0 ~ 48)
행 = INT(k / 7)   (몫)       열 = MOD(k, 7)   (나머지)
예: k = 9 → 행 1, 열 2 → INDEX(A2:G8, 2, 3) 의 값을 확인
코드 순서
  1. 격자를 A2:G8에 넣습니다(2행 = 행 0).
  2. J2:K50에 수식을 49줄 넣습니다 (Python 반복문으로 문자열 생성).
  3. 경로 표를 격자 아래에 넣습니다.
  4. Block 계열(X = J, Y = K, 선 없음, 검정 사각형)과 Path 계열(X = 열, Y = 행)을 차트에 넣습니다.
  5. Python으로 같은 Block 좌표를 계산해 출력해 검산합니다.
숫자로 확인

Block 16칸이 출력되고, 첫 칸 (3, 0)은 격자 첫 줄 0 0 0 1 …의 네 번째 칸(열 3)입니다. 엑셀에서 열면 수식이 계산되어 sample_data의 차트 1과 같은 그림이 나옵니다.

자주 하는 실수
  • 길 칸에 0이나 ""를 넣으면 (0, 0)에 벽이 그려집니다. 꼭 NA().
  • 차트 X에 행, Y에 열을 넣으면 지도가 대각선으로 뒤집힙니다. X = 열, Y = 행.
