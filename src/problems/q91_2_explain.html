문제를 한 줄로

1000줄짜리 궤적 CSV를 엑셀 시트에 넣고, 시간에 따른 위치·속도·가속도를 선 그래프로 그리는 문제입니다.

풀이 아이디어

CSV에서 읽은 값은 글자입니다. 엑셀에 글자 그대로 넣으면 차트가 숫자로 인식하지 못하므로 float()로 바꿔 넣습니다.

가로축이 시간(숫자)이므로 분산형 차트를 쓰고, 점이 1000개라 표식은 없애고 선만 그립니다. 계열 이름은 머리글 칸(1행)을 포함한 범위를 주고 title_from_data=True로 가져옵니다.

코드 순서
  1. 머리글은 그대로, 데이터는 숫자로 바꿔 시트에 씁니다.
  2. X = A2:A1001(시간)을 공통으로 두고 B, C, D열마다 계열을 만듭니다.
  3. marker.symbol = "none"으로 표식을 끕니다.
  4. 열마다 최솟값, 최댓값을 출력해 데이터가 맞는지 확인합니다.
숫자로 확인
Pos: 0.5236 → 1.5708 rad   (π/6 → π/2, 30° → 90°)
Vel: 0 → 1.0461 → 0        (가운데에서 최대)
Acc: +1.0472 → −1.0472     (앞 절반 가속, 뒤 절반 감속)

BBPB는 t_b = t_f/2라서 가속도가 a = 4Δq/t_f² = 4×1.0472/4 = 1.0472로 정해집니다. 위치 최댓값이 정확히 목표 1.5708이라 수정된 코드로 만든 데이터인 것이 확인됩니다.

자주 하는 실수
  • 숫자로 바꾸지 않고 넣으면 엑셀에서 「텍스트로 저장된 숫자」가 되어 차트가 비거나 0으로 그려집니다.
  • 단위가 다른 세 값을 한 축에 그리면 작은 값이 납작해 보입니다. 필요하면 차트를 나누거나 보조축을 씁니다.
