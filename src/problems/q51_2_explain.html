문제를 한 줄로

오차 값이 순서대로 주어질 때, PID 제어기가 매 순간 내보내는 P, I, D 값과 출력 u를 손으로 계산하듯 구하는 문제입니다.

풀이 아이디어

P = Kp × 지금 오차 (지금 얼마나 틀렸나)

I = 지금까지의 Ki × Ts × 오차를 모두 더한 값 (그동안 얼마나 오래 틀렸나)

D = Kd × (지금 오차 − 이전 오차) / Ts (오차가 얼마나 빨리 바뀌나). 첫 샘플은 이전 값이 없어 D = 0으로 둡니다.

u = P + I + D 입니다.

코드 순서
  1. 주석 줄을 빼고 오차 값만 리스트로 읽습니다.
  2. I = 0, e_prev = 첫 오차로 시작합니다.
  3. 각 샘플에서 I를 먼저 더하고, D와 P를 계산해 u를 씁니다.
  4. e_prev를 지금 오차로 바꿉니다.
숫자로 확인
Kp = 2.0, Ki = 0.5, Kd = 0.1, Ts = 0.1
k=0, e=1.00: P = 2.000, I = 0.5×0.1×1.00 = 0.050, D = 0      → u = 2.050
k=1, e=0.80: P = 1.600, I = 0.050 + 0.040 = 0.090,
             D = 0.1×(0.80 − 1.00)/0.1 = −0.200            → u = 1.490
k=5, e=−0.05: P = −0.100, I = 0.135, D = 0.1×(−0.05−0.10)/0.1 = −0.150 → u = −0.115

오차가 줄어드는 중이라 D는 계속 음수(브레이크 역할)입니다. 마지막에는 오차가 음수가 되어 u도 음수로 바뀝니다.

자주 하는 실수
  • D 계산에서 순서를 (이전 − 지금)으로 뒤집으면 부호가 반대가 됩니다.
  • I를 매번 새로 계산하지 말고 계속 더해 갑니다(누적).
