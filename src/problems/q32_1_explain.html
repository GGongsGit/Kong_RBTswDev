문제를 한 줄로

가속 → 일정 속도 → 감속 모양(사다리꼴 속도)으로 0°에서 90°까지 2초 동안 움직일 때, 가속 시간 t_b와 최대 속도, 몇 시점의 위치를 구하는 문제입니다.

풀이 아이디어

속도 그래프 아래 넓이가 이동 거리입니다. 사다리꼴 넓이 = 높이 × (윗변 + 아랫변) / 2 이고, 높이 v = a·t_b, 아랫변 t_f, 윗변 t_f − 2t_b 이므로:

Δq = a·t_b·(t_f − t_b)   →   t_b² − t_f·t_b + Δq/a = 0

이 이차방정식의 근의 공식 중 작은 근이 t_b입니다. 위치는 가속 구간에서 ½at², 등속 구간에서 직선, 감속 구간은 끝에서 거꾸로 ½a(t_f − t)²만큼 덜 간 곳입니다.

코드 순서
  1. 입력 값을 읽고 각도를 라디안으로 바꿉니다.
  2. t_b = (t_f − √(t_f² − 4Δq/a)) / 2
  3. v_max = a·t_b
  4. 구간을 나눠 위치를 계산하는 함수 q_at(t)를 만들고 0, 0.5, … 2.0 에서 값을 씁니다.
숫자로 확인
Δq = 90° = 1.5708 rad,  t_f = 2,  a = 2
판별식 = 2² − 4×1.5708/2 = 4 − 3.1416 = 0.8584,   √ = 0.9265
t_b = (2 − 0.9265) / 2 = 0.5367 s,   v_max = 2×0.5367 = 1.0735 rad/s
q(0.5) = ½×2×0.5² = 0.25 rad = 14.32°   (아직 가속 중)
q(1.0) = 45°  (대칭이라 정확히 가운데)

q(1.5) = 90 − 14.32 = 75.68°로 q(0.5)와 대칭입니다.

자주 하는 실수
  • 큰 근을 고르면 t_b > t_f/2가 되어 가속 구간과 감속 구간이 겹칩니다. 작은 근입니다.
  • 판별식이 음수면 가속도가 부족한 것입니다. 이때는 계산하지 말고 「불가」로 처리해야 합니다(다음 문제).
