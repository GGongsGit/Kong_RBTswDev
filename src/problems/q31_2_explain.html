문제를 한 줄로

세 관절이 각자 최대 속도로 움직이면 도착 시간이 다르니, 모두 같은 시간에 도착하도록 속도를 맞추는 문제입니다.

풀이 아이디어

각 관절이 혼자 움직일 때 걸리는 시간은 「이동 거리 ÷ 최대 속도」입니다. 셋이 동시에 도착하려면 가장 오래 걸리는 관절에 맞춰야 합니다(빠른 관절이 천천히 가는 건 되지만, 느린 관절이 더 빨리 갈 수는 없으니까). 그 시간을 T_sync로 정하고, 각 관절 속도는 이동 거리 ÷ T_sync 입니다.

코드 순서
  1. # 줄을 건너뛰며 축 이름, 시작, 목표, 최대 속도를 읽습니다.
  2. T_alone = |목표 − 시작| / v_max 를 축마다 구합니다.
  3. T_sync = max(T_alone)
  4. v_sync = (목표 − 시작) / T_sync (부호 유지)
숫자로 확인
J1: |90 − 0| / 30 = 3 s     J2: |−15 − 45| / 15 = 4 s     J3: |60 − (−30)| / 45 = 2 s
T_sync = 4 s
v_sync: J1 = 90/4 = 22.5,  J2 = −60/4 = −15.0,  J3 = 90/4 = 22.5 °/s

J2가 가장 느려서 기준이 되고, J2는 원래 최대 속도 그대로, J1·J3은 느리게 움직입니다.

자주 하는 실수
  • 가장 짧은 시간(min)을 고르면 느린 관절이 최대 속도를 넘게 됩니다. 반드시 max.
  • J2처럼 목표가 시작보다 작으면 속도가 음수입니다. 시간 계산에만 절댓값을 씁니다.
