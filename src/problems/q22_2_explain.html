문제를 한 줄로

IK로 구한 각도가 정말 맞는지, 그 각도를 FK(순기구학)에 다시 넣어 목표 위치가 나오는지 확인하는 문제입니다.

풀이 아이디어

IK는 「위치 → 각도」, FK는 「각도 → 위치」라서 서로 반대 계산입니다. IK 결과를 FK에 넣었을 때 원래 위치가 나오면 IK가 맞은 것입니다. 이것을 검산이라 합니다. 컴퓨터 계산에는 아주 작은 반올림 오차(10⁻¹⁶ 정도)가 남으므로, 오차가 10⁻⁹보다 작으면 같은 것으로 봅니다.

코드 순서
  1. IK 함수(부호 s로 두 해 중 하나)와 FK 함수를 만듭니다.
  2. 각 목표 점마다 두 해를 구해 FK에 넣습니다.
  3. FK 결과와 목표의 거리 np.hypot(xe − x, ye − y)를 오차로 봅니다.
  4. 두 오차 중 큰 값이 10⁻⁹보다 작으면 OK, 아니면 NG.
숫자로 확인

출력 결과의 오차가 1.6e−16, 2.8e−16, 0.0e+00입니다. 1.6e−16은 0.00000000000000016이라는 뜻으로, 사실상 0입니다. 세 점 모두 OK입니다.

(0.6, 0.8)은 r = 1.0, L₁ = L₂ = 1이라 삼각형이 정삼각형에 가깝고, (1.5, −0.5)처럼 y가 음수인 점도 atan2 덕분에 맞게 풀립니다.

자주 하는 실수
  • 오차를 ==로 비교하면 거의 항상 False입니다. 실수는 「충분히 작은지」로 비교합니다.
  • 두 해를 모두 검산해야 합니다. 한쪽 해만 맞고 다른 쪽이 틀리는 실수가 흔합니다.
